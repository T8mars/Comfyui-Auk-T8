# Comfyui-Auk-T8 2.0.7

- 新增 **AuK 音频裁剪 / 时长** 原生节点：按秒截取，保留声道和采样率，输出 AUDIO、真实时长 FLOAT 和说明。
- 生成节点新增可点击的 **↻ 自动适配时长** 按钮、可见时长模式及实际目标时长输出；旧自动/手动选项和原前三个输出端口保持兼容。
- 16 个音频工作流已连接裁剪节点，提供全部 17 个任务的标准可拖入 JSON。
- 按真实样本数校验输入 30 秒上限；长文本估时超限时提示分段，不再静默截断。输入与输出依旧各自最多 30 秒。
- 校验非法 Seed/NFE/CFG/Sway 和音频数据；仅在模型峰值越界时降低增益，避免标准 FLAC 导出截幅，并在 JSON 记录调整。
- 修正说明区布局、前端说明缓存和旧画布残留超限时长的恢复；完善中英文使用说明。

验证：十轮检查、129 项自动测试、17 个任务真实推理、真实前端 JSON 导入运行、六项服务边界测试，以及音量峰值保护的定向回归。详见 [检查报告](https://github.com/T8mars/Comfyui-Auk-T8/blob/main/planning/audit-10-rounds-v2.0.7.md)。

情绪、强方言去口音及指定说话人的主观效果仍受模型能力影响，执行回归通过不代表这些效果对所有输入都稳定。

更新后重启 ComfyUI 并刷新浏览器。旧画布请添加裁剪节点，或重新导入新工作流。
